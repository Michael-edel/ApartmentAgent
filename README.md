# ApartmentAgent

ApartmentAgent — сервис мониторинга и аналитики объявлений о продаже квартир в Астане с мобильной PWA-панелью для iPhone.

## Цель MVP

Сервис принимает ссылки на объявления через веб-интерфейс или API, сохраняет карточки квартир, рассчитывает цену за квадратный метр, применяет пользовательские фильтры и формирует рейтинг объекта.

## Базовые критерии поиска

- город: Астана;
- полноценная 2-комнатная квартира;
- цена до 30 000 000 ₸;
- площадь 55–70 м²;
- не первый этаж;
- не последний этаж без технического этажа;
- предпочтительно кирпичный или монолитный дом;
- возможность покупки через Отбасы Банк.

## Архитектура MVP

- FastAPI — HTTP API и раздача PWA;
- адаптивная PWA-панель — работа в Safari и установка на главный экран iPhone;
- PostgreSQL — объявления, enrichment-поля, AI-анализ, snapshots цены и статусы импорта;
- Telegram Bot — уведомления о новых сильных объектах и изменении цены;
- Docker Compose — локальный запуск.

## Безопасность и ограничения

Проект не должен обходить CAPTCHA, 403/429, ограничения доступа или маскировать автоматизацию. При блокировке проверка прекращается. Основной сценарий MVP — анализ ссылок, полученных пользователем или официальными уведомлениями.

## Запуск на Windows

```powershell
git clone https://github.com/Michael-edel/ApartmentAgent
cd ApartmentAgent
Copy-Item .env.example .env
docker compose up --build
```

После запуска:

- мобильная панель: `http://localhost:8000`;
- Swagger: `http://localhost:8000/docs`;
- health-check: `http://localhost:8000/health`.

## Открытие на iPhone в домашней сети

1. Узнайте IPv4-адрес компьютера командой `ipconfig`.
2. Убедитесь, что iPhone подключен к той же Wi‑Fi сети.
3. Откройте в Safari `http://IP_КОМПЬЮТЕРА:8000`, например `http://192.168.1.15:8000`.
4. Нажмите **Поделиться → На экран «Домой» → Добавить**.

Для доступа вне домашней сети нужен HTTPS-домен или безопасный туннель/VPN. Не открывайте порт 8000 напрямую в интернет без аутентификации и TLS.

- адаптивная панель для iPhone;
- установка как PWA;
- офлайн-кэш оболочки;
- список квартир и фильтр по рейтингу;
- ручное добавление ссылки;

## API

- `POST /api/v1/search/run` — поиск и автоматический импорт найденных карточек;
- `GET /api/v1/search/results` — найденные ссылки и статус автоимпорта;
- `POST /api/v1/listings/import` — импорт и enrichment одной ссылки;
- `GET /api/v1/listings` — карточки с AI-анализом и историей цены;
- `GET /api/v1/listings/{id}/price-history` — snapshots цены;
- `POST /api/v1/listings/{id}/ai-analysis` — пересчитать AI-анализ;
- `GET /api/v1/notifications/status` — состояние Telegram.

## Конфигурация новых функций

- `AUTO_IMPORT_ENABLED=true` включает импорт после каждого поиска. При ответе Krisha `403/429` или CAPTCHA новые запросы к источнику прекращаются, а оставшиеся результаты помечаются как `blocked`.
- `AI_ENABLED=true` включает explainable local-rules AI. `AI_REMOTE_ENABLED=true` и `OPENAI_API_KEY` включают дополнительный внешний анализ; при ошибке автоматически используется локальный fallback.
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` включают уведомления. Новые объекты фильтруются по `TELEGRAM_NOTIFY_MIN_SCORE`, а изменения цены дедуплицируются по event key.
