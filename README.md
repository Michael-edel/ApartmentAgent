# ApartmentAgent

Версия приложения **0.23.0**. Браузерное расширение с проверкой связи **0.4.14**.
API, `/health` и заголовок панели используют версию установленного пакета,
заданную в `pyproject.toml`.

Сервис поиска квартир в Астане и Экибастузе с адаптивной панелью.
Сохраняет объявления, историю цены и других изменений, рассчитывает цену за м² и
объясняет соответствие выбранным критериям.

## Что нового в 0.23.0

- [Поиск по нарисованной области](#как-нарисовать-область-на-карте) оставляет
  в результатах и на карте только объявления Krisha и OLX с точными
  координатами внутри области или на её границе.

  исправлений карточек. В профиле поиска можно сохранить отбор по собственникам и
  дополнительные условия.
- Добавлены журнал импорта, проверка связи с расширением, экспорт CSV и JSON
  и скрипты резервного копирования PostgreSQL.
- HTTP 468 при загрузке отдельной карточки Krisha приостанавливает загрузку
  карточек. Ручной и фоновый поиск по выдаче Krisha продолжаются по своим
  правилам повторных запросов.
- В разделе «Квартиры» показывается до 12 сохранённых карточек на странице.
  В карточке сразу доступно одно фото, если оно есть. Полная галерея,
  встроенная карта и сравнение цены за м² загружаются при раскрытии.

## Аналитика, качество и осмотр

- **«Индекс цен Астаны»** показывает медиану и 25-й/75-й перцентиль по
  ежедневным срезам активных сохранённых предложений. Выберите городскую
  выборку, район или ЖК, тип дома, комнатность, площадь и период. Медиана и
  квартили рассчитываются при наличии пяти уникальных квартир за день.
- В карточке **«Индекс цен и ликвидность»** показывает историю цены предложения,
  медиану района и Астаны, сравнение за 30 дней, число снижений и доли
  завершившихся предложений за 30/90 дней. Отсчёт срока идёт по наблюдениям
  приложения. Отметка о продаже и снятие с площадки учитываются отдельно.
  Графики заполняются с первого среза после обновления.
- **«Качество данных и исправления»** показывает заполненность, число фото,
  наличие координат, сведения о ремонте, ипотеке, санузлах и продавце. Подсказки
  предлагают сверить необычную площадь, тип рынка и год постройки.
  После подтверждения дубля здесь видны объединённые характеристики и их
  источники, а также ссылки, цены, фото и история каждого предложения.
  Для исправления выберите поле и укажите причину. Журнал хранит прежнее и
  новое значения с датой. Повторный импорт сохраняет ручное значение.
- **«Чек-лист осмотра квартиры»** хранит отметки, вопросы, заметки, итог и до
  десяти вложений на карточку. Форматы JPEG, PNG, WebP и PDF, до 5 МБ каждый.
- В условиях поиска можно указать район, выбрать
  планировку, балкон или лоджию, гардеробную и кухню-гостиную, искать фразу из
  объявления и скрывать явный наличный расчёт или предложения с ценой «от».
  Поиск фразы буквальный и показывает цитату.
  Радиус от важной точки рассчитывается по прямой по точным координатам.

## Диагностика импорта и уведомления

В разделе **«Состояние источников и журнал импорта»** видны отдельные счётчики
Krisha и OLX и время окончания каждой паузы. При HTTP 403, 429 или 468
пауза автоматически растёт с 1 минуты до 1 часа отдельно для поиска и
загрузки карточек каждой площадки. Если Krisha ограничивает загрузку карточки,
поиск по её выдаче продолжается. Серверный автоимпорт возобновляется в
последующих циклах поиска после окончания паузы загрузки карточек.
Для статуса связи обновите расширение до 0.4.14 и оставьте браузер открытым.
Очередь проверки отдаёт приоритет карточкам с рейтингом от 85 и ценой в
пределах 10% выше личной цели. Архив и недоступность устанавливаются по
проверенной странице или HTTP 404/410.

В `.env` можно отдельно включить уведомления о деградации импорта
(`TELEGRAM_PARSER_ALERTS_ENABLED=true`) и ежедневный обзор
(`TELEGRAM_DAILY_DIGEST_ENABLED=true`). Обзор по умолчанию формируется в 09:00
по времени Астаны, час настраивается через `TELEGRAM_DIGEST_HOUR`.
В обзоре есть до семи ссылок на новые объявления, крупные снижения, отправленные уведомления
о достижении цели и подтверждённые изменения доступности.

## Экспорт и резервные копии

В разделе **«Квартиры» → «Экспорт сохранённых квартир»** доступны CSV для Excel
и JSON по всем сохранённым объявлениям, включая скрытые и неактивные.
Полная резервная копия PostgreSQL включает вложения. Из папки репозитория
в PowerShell 7 укажите свою существующую папку для архива:

```powershell
pwsh -File scripts/backup.ps1 -Project apartmentagent -BackupPath C:\Backups\apartmentagent.dump
pwsh -File scripts/backup-install-schedule.ps1 -Project apartmentagent -DestinationDir C:\Backups -DailyAt 03:00
```

Для восстановления оставьте рядом `.dump` и `.dump.meta.json`. Запустите только
PostgreSQL в отдельном Compose-проекте и восстановите архив в его пустую базу:

```powershell
docker compose -p apartmentagent-restore up -d db
pwsh -File scripts/restore.ps1 -Project apartmentagent-restore -BackupPath C:\Backups\apartmentagent.dump
```

### 1. Профили поиска

1. В разделе **«Поиск новых объявлений»** задайте город, тип рынка, количество
   комнат, цену, общую площадь, санузлы, отбор по залогу и дополнительные условия.
2. Раскройте **«Профили поиска»**, введите название, например «Астана для семьи»,
   и нажмите **«Сохранить новый»**.
3. Выберите сохранённый профиль и нажмите **«Применить»**. Его критерии загрузятся
   в форму и будут действовать в выдаче и на карте. Нажмите **«Искать сейчас»**,
   чтобы сразу запросить свежие объявления.
4. Чтобы изменить название или переключить **«Искать в фоне»**, нажмите
   **«Сохранить имя и фон»**. Чтобы записать в профиль критерии из формы, нажмите
   **«Записать текущие критерии»**, затем **«Применить»**.

Фоновый поиск должен быть включён в настройках приложения. Для профилей Астаны
его можно включить отдельно. Профили, которые сейчас не применены, в фоне
сохраняют найденные ссылки. Для автоимпорта их объявлений примените нужный
профиль и запустите поиск. Фильтры отображения по продавцу и берегу выбираются
в панели отдельно.

### 2. Заметки и этап просмотра

1. В сохранённой карточке раскройте **«Заметки и просмотр»**.
2. Введите заметку, выберите этап **«Новая»**, **«Позвонить»**,
   **«Просмотр назначен»**, **«Осмотрена»** или **«Отказ»**. При необходимости
   укажите дату и время просмотра.
3. Нажмите **«Сохранить заметку и этап»**. Текущий этап отображается рядом
   с названием блока.

### 3. Целевая цена

1. Отметьте сохранённую квартиру галочкой **«Понравилась»**.
2. Раскройте **«Контроль цены и изменения»**, укажите целевую цену в тенге
   и нажмите **«Сохранить цель»**.
3. Чтобы учитывать другие предложения той же квартиры, включите
   **«Учитывать похожие объявления той же квартиры»**. Совпадения по последним
   сохранённым ценам появятся в блоке **«Предложения не дороже цели»**.

При импорте или проверке карточек приложение сверяет цены с целью и отправляет
уведомление при настроенном [Telegram](#контроль-цены-и-настройки). Снятие
галочки **«Понравилась»** приостанавливает контроль. Чтобы удалить цель, очистите
поле цены и нажмите **«Сохранить цель»**.

### 4. История изменений и более ранние объявления

В карточке откройте **«Контроль цены и изменения»**, затем **«Изменения объявления»**.
При импорте и повторных проверках здесь сохраняются изменения цены, описания,
ремонта, ипотеки, залога, типа продавца и других полученных характеристик.
Для каждого изменения видны предыдущие и новые значения.

В этом же блоке показаны дата, когда приложение впервые увидело объявление,
и срок наблюдения. Если в базе есть более раннее связанное объявление, здесь
будут дата первого наблюдения, ссылка и признак подтверждённого или возможного
совпадения.

### 5. Обязательные условия и пожелания

1. В форме поиска раскройте **«Дополнительные условия и предпочтения»**.
2. Укажите, как учитывать первый и последний этаж. При необходимости задайте
   год постройки **«от»** и **«до»** и минимальную площадь кухни. Для каждой
   границы можно выбрать свой режим.
3. Нажмите **«Искать сейчас»** или сохраните критерии в профиль и примените его.

Обязательные условия оставляют в выдаче и на карте только подтверждённые
совпадения. Например, обязательная кухня от 12 м² требует указанной площади
кухни от 12 м². Пожелание влияет на рейтинг при известном значении. Причины
оценки видны в блоке **«Почему такая оценка»** в карточке. Найденные и
сохранённые квартиры можно отсортировать по году постройки в обе стороны.

### 6. Скрытие квартиры

Нажмите **«Скрыть»** в найденном объявлении или сохранённой карточке, чтобы
убрать её из обычной выдачи и с карты. Для возврата включите
**«Показывать скрытые объявления»** в разделе **«Ссылки из поиска»** или
**«Показывать скрытые квартиры»** в разделе **«Квартиры»**, затем нажмите
**«Вернуть в список»**. У похожей сохранённой квартиры появится предупреждение
о возможном совпадении со скрытой.

### 7. Ручное подтверждение дублей

1. В сохранённой карточке раскройте **«Вероятные дубли»**. Сверьте доступные
   фотографии, цены, типы продавцов и исходные объявления.
2. Нажмите **«Одна квартира»** или **«Разные квартиры»**. Чтобы проверить пару,
   которой нет в списке, используйте **«Сравнить с другой сохранённой квартирой»**.
3. Для отмены нажмите **«Отменить решение»**. Пары с решением **«Разные квартиры»**
   находятся в списке **«Отмечены как разные»**.

Решения учитываются в группировке дублей, ближайших аналогах и контроле
целевой цены по похожим объявлениям.

### 8. Маршруты до важных мест

1. В сохранённой карточке раскройте **«Маршруты до важных мест»**.
2. Введите название и адрес с городом, например «Работа» и «Астана, Абая 12»,
   затем нажмите **«Добавить место»**. Место будет доступно и из других карточек.
3. Нажмите на сохранённый адрес. Яндекс Карты откроют маршрут в новой вкладке.
   Для точки отправления используются координаты квартиры или её адрес.

## Запуск на Windows 11 / PowerShell 7

Нужны Git и запущенный Docker Desktop с Linux containers и Docker Compose.
Python на компьютере для запуска через Docker не требуется.

```powershell
git clone https://github.com/Michael-edel/ApartmentAgent.git
cd ApartmentAgent
if (!(Test-Path .env)) { Copy-Item .env.example .env }
docker compose up -d --build
docker compose ps
Invoke-RestMethod http://localhost:8000/health
```

- Панель: http://localhost:8000
- Swagger/API: http://localhost:8000/docs
- Журнал: `docker compose logs --tail=150 api`
- Остановить: `docker compose down`

PostgreSQL хранит данные в томе `postgres_data`. Обычный `down` сохраняет том.
Не используйте `down -v`, если данные нужны. При запуске создаются таблицы и
добавляются недостающие колонки старых версий. Перед обновлением рабочей базы
сделайте резервную копию.

Для обновления чистой локальной копии:

```powershell
git pull --ff-only origin main
docker compose up -d --build
```

После обновления перезагрузите панель через Ctrl+F5. Для браузерного импорта
проверьте, что установлено расширение **0.4.14**.

Если панель всё ещё показывает старые подсказки о версии расширения, откройте
`http://localhost:8000/?v=0.23.0`. В блоке «Автопроверка объявлений» есть кнопка
«Дополнить карточки», а после запуска отображается режим «дополнение карточек».
Подсказка панели о требуемой версии не является проверкой установленного расширения:
его фактическую версию можно посмотреть на странице расширений браузера.

## Критерии поиска

В разделе **«Поиск новых объявлений»** выберите параметры поиска.

- город — **Астана** по умолчанию или **Экибастуз** для ручного поиска;
- тип рынка — **Все**, **Новостройки** или **Вторичное жильё**;
- минимальное количество комнат — от 2, от 3 или от 4;
- верхнюю границу цены в тенге и, при необходимости, нижнюю;
- минимальную площадь и, при необходимости, максимальную. Пустое поле максимума означает поиск без верхней границы;
- при необходимости «От 2 санузлов».

Начальные параметры — Астана, от 2 комнат, до 30 млн ₸, 55–70 м², без ограничения
по числу санузлов. Если задана нижняя граница цены, отбор требует точную цену
в заданном диапазоне.

### Как нарисовать область на карте

1. В **«Поиск новых объявлений»** выберите город и раскройте **«Район,
   планировка и слова в объявлении» → «Нарисовать область на карте»**.
2. Поставьте минимум три точки по порядку вдоль границы нужного участка.
   Если граница пересеклась, нажмите **«Убрать последнюю точку»** или
   **«Очистить область»** и нарисуйте её заново.
3. Нажмите **«Завершить рисование»**. Карта соединит последнюю точку с первой.
   Затем нажмите **«Искать сейчас»**, чтобы сохранить и применить область.
4. Посмотрите **«Ссылки из поиска»** и откройте **«Карта квартир»** рядом с
   результатами. Отбор по области действует в обоих местах для Krisha и OLX.

Проходят объявления с точными координатами внутри области или на самой границе.
Объявления с приблизительным местоположением или без координат исключаются
автоматически. Галочка **«Скрывать объявления с неизвестными значениями
выбранных условий»** для отбора по области не требуется. Остальные критерии,
включая цену, площадь и число комнат, продолжают действовать.

Ранее сохранённые карточки остаются в разделе **«Квартиры»**. Если карточка
не проходит условия поиска, на ней видна соответствующая отметка. Чтобы
вернуться к поиску по всему городу, нажмите **«Очистить область»** и снова
**«Искать сейчас»**.

### Как выбрать тип рынка

В разделе **«Поиск новых объявлений»** выберите значение в поле **«Тип рынка»**
и нажмите **«Искать сейчас»**.

- **Все** показывает оба типа и объявления с неизвестным типом рынка.
- **Новостройки** включает фильтр новостроек на Krisha. В выдаче остаются
  объявления с подтверждённой меткой новостройки.
- **Вторичное жильё** ищет на Krisha объявления с меткой **«Хозяин недвижимости»**.
  Сохранённая квартира также попадёт в этот режим, если при импорте получен
  явно указанный вторичный тип.
  Чтобы просмотреть предложения риелторов из общей выдачи, выберите **«Все»**.

Тип рынка сохраняется вместе с критериями и входит в профиль поиска. Выбор
применяется к выдаче, карте, сохранённым карточкам и сравнению понравившихся.
Подтверждённый тип может заполниться в старой карточке при новом поиске или импорте.

### Как применяется выбранный город

При первом запуске в поле **«Город»** выбрана **Астана**. Чтобы посмотреть
**Экибастуз**, выберите его в этом поле и нажмите **«Искать сейчас»**.
Для возврата выберите **Астана** и снова нажмите **«Искать сейчас»**.
Приложение сохраняет выбранный город и восстанавливает его после перезапуска.

Фоновый поиск и периодическая проверка цен работают по Астане. Пока в панели
выбран Экибастуз, фоновый поиск Астаны собирает ссылки по включённым профилям
Астаны. Если таких профилей нет, он использует остальные текущие критерии
формы с городом Астана. Для Экибастуза можно сохранить профиль и применять
его вручную. Для добавления отдельной квартиры из Экибастуза используйте
ручной импорт по номеру или ссылке.

Поиск, карта, обычный список сохранённых карточек и сравнение понравившихся
используют выбранный город. При смене города старые ссылки и карточки остаются
в базе. Карточка другого города доступна по прямой ссылке на неё.

На карте действуют те же критерии города. Фильтр и надбавка за левый берег Есиля
доступны для квартир в Астане.

Для нескольких наборов критериев используйте [профили поиска](#1-профили-поиска).

### Отбор по санузлам

Строка «Санузел — 2 с/у и более» подтверждает минимум два санузла. После получения
этих данных дополнительная проверка этого критерия не нужна. Карточка показывает
«не менее 2», сохраняя отличие от точного количества.
Подтверждённое количество от двух выделяется зелёной меткой с галочкой и в
найденных объявлениях, и в сохранённых карточках. Неизвестное количество
остаётся нейтральным.

При включённом отборе от двух санузлов:
- известное количество от двух проходит;
- известное количество меньше двух исключается;
- неизвестное количество также скрывается из списка найденных объявлений;
- в списке остаются только квартиры с подтверждённым количеством от двух.

Поисковая выдача часто не содержит число санузлов. Сам факт открытия страницы
не передаёт данные в приложение: для этого нужен успешный серверный импорт,
расширение, bookmarklet или ручной ввод. Неподтверждённый статус означает отсутствие
данных в приложении, а не отсутствие строки на сайте. Прямой запрос Krisha пока
не передаёт отдельный параметр санузлов: отбор выполняется по полученным данным.

### Сортировка найденных квартир

В разделе **«Ссылки из поиска»** выберите порядок в списке рядом с кнопкой
обновления. По умолчанию первыми идут новые объявления. Сортировка по рейтингу,
общей цене, цене за м² и площади доступна по возрастанию и по убыванию.
При сортировке по общей цене или цене за м² объявления без точной цены, в том
числе с ценой «от», идут в конце списка.

Сортировка **«По типу продавца»** доступна в поисковой выдаче и в разделе
«Квартиры». Сначала идут хозяева, затем Крыша Агенты и риелторы. Прочие и неизвестные
типы идут последними одной группой. Внутри каждой группы сначала идут новые объявления.

В прямой выдаче Krisha приложение считывает метки «Хозяин недвижимости» и
«Специалист» с подтверждённой личностью. Метка привязывается к объявлению, когда
номер карточки в выдаче совпадает с номером в ссылке. Хозяин отображается как
«Хозяин недвижимости», а специалист — как «Риелтор · личность подтверждена».

Когда объявление найдено повторно, метка из выдачи заполняет пропуск в сохранённой
карточке с той же ссылкой. При импорте она также используется, если страница
объявления не передала тип продавца. Если тип уже получен со страницы, он имеет
приоритет. Для старых карточек можно запустить **«Дополнить карточки»** в блоке
«Автопроверка объявлений».

Чтобы найти предложения от хозяев, выберите **«Только собственники»** и нажмите
**«Искать сейчас»**. Для этого запуска используется фильтр Krisha «От хозяев».
В результатах остаются объявления, в которых Krisha указала, что продавец — хозяин.
Сохранённые квартиры можно отдельно отфильтровать по типу продавца над карточками.

Галочка **«Понравилась»** есть у найденных и сохранённых квартир. Отметка
сохраняется после перезагрузки и переносится при импорте. Выберите
**«Сначала понравившиеся»**, чтобы поднять отмеченные квартиры в начало списка.
Нажмите **«Сравнить понравившиеся»** и выберите от двух до четырёх квартир. В одной
таблице показаны цена, цена за м², адрес, этаж, санузлы, ремонт, ипотека, залог и
тип продавца. Если часть сведений ещё не получена, таблица отмечает пропуски.

Кнопка **«Карта квартир»** рядом с результатами открывает карту подходящих
квартир выбранного города. Выберите площадку над картой, затем нажмите на метку,
чтобы увидеть цену и перейти в карточку или объявление. При поиске без
нарисованной области пунктирная метка OLX показывает примерное местоположение.
Если у той же квартиры есть точная метка из Krisha, карта показывает её.
Объявления без меток перечислены под картой. При
[поиске по области](#как-нарисовать-область-на-карте) остаются только метки с
точными координатами внутри границы. Для определения берега используются точные
координаты.
Подложка карты загружается из [OpenStreetMap](https://www.openstreetmap.org/copyright).

## Пакетная проверка санузлов

В панели поиска нажмите **«Проверить неизвестные»**. Очередь включает объявления
без подтверждённого количества санузлов, подходящие по сохранённым комнатам,
цене и площади. Ссылки на одну квартиру объединяются; известные значения повторно
не проверяются. Изменение поисковых условий после запуска не меняет уже созданную очередь.

Нужно расширение **ApartmentAgent Browser Import 0.4.1** с включённым импортом
и настроенным адресом приложения. После обновления расширения перезагрузите панель.
Во время проверки браузер должен быть открыт. Расширение последовательно открывает
объявления в одной служебной вкладке и использует обычный браузерный импорт.
Настройка отдельного API-ключа не нужна.

После сохранения данные появляются в карточке и обновляют результат поиска:
два санузла и более проходят строгий отбор, один санузел не проходит, неизвестное
значение остаётся скрытым при включённом условии «От 2 санузлов».
Панель показывает прогресс и позволяет поставить очередь на паузу, продолжить
или остановить её. Прогресс хранится в базе, текущее задание — также в расширении.

Между заданиями есть пауза не менее 15 секунд; браузер может увеличить интервал.
При капче, ограничении доступа или ошибке связи очередь останавливается.
Единичные неактуальные объявления и страницы без обязательных данных пропускаются
как неподтверждённые. Три подряд страницы, с которых не удалось прочитать основные
поля, останавливают очередь с причиной ошибки; это не обозначается как пауза пользователя.
Проверку сайта нужно пройти вручную в оставленной вкладке, затем нажать
«Продолжить». Решение капчи не автоматизируется. Ни очереди, ни расширение
не гарантируют, что сайт предоставит данные для каждого объявления.

## Сохранение и браузерный импорт

### Объявления OLX.kz

Выберите город и критерии, затем нажмите **«Искать сейчас»**. Krisha и OLX
проверяются в одном запуске. Результаты появляются в **«Ссылках из поиска»**.
При включённом автоимпорте (`AUTO_IMPORT_ENABLED=true`, по умолчанию)
приложение само загружает данные доступных объявлений и сохраняет их в
**«Квартиры»**. Фоновый поиск по Астане использует те же источники.
Для OLX за запуск просматривается до трёх страниц публичного
каталога с фильтрами цены и площади. Комнаты, тип рынка и другие условия
проверяются по данным объявления. Астана используется по умолчанию, Экибастуз
можно выбрать для ручного запуска поиска.

Чтобы добавить конкретное объявление OLX, вставьте его ссылку в
**«Быстрое добавление»** и нажмите **«Импортировать автоматически»**.
**«Проверить квартиру»** загружает актуальную цену с площадки, изменение
сохраняется в истории цены. Плановая проверка также обрабатывает ссылки OLX.

Если такая квартира уже сохранена с Krisha, раскройте **«Вероятные дубли»**
в карточке. При совпадении приложение покажет ссылку и цену каждого объявления.
Кнопки **«Одна квартира»** и **«Разные квартиры»** позволяют уточнить совпадение.
Если совпадение отклонено и других совпадений между площадками нет, карточки
снова получают одноцветные рамки.
В выборке ближайших аналогов совпавшие объявления считаются одной квартирой.

#### Пример ЖК Aviator 2

Астана, Сарытогай 13, 4 комнаты, этаж 6 из 7. В проверенной карточке левая
половина рамки жёлтая, правая зелёная. Раскройте **«Вероятные дубли»**, чтобы
увидеть два предложения. Ниже цены, сохранённые при проверке 13 ноября 2026 года.

| Площадка | Цена | Объявление |
| --- | ---: | --- |
| Krisha | 47 000 000 ₸ | [№1017226006](https://krisha.kz/a/show/1017226006) |
| OLX | 47 000 000 ₸ | [ЖК Aviator 2](https://www.olx.kz/d/obyavlenie/prodaetsya-prostornaya-4-komnatnaya-kvartira-v-zhk-aviator-2-IDrfHFK.html) |

В «Быстром добавлении» можно также указать номер объявления или ссылку Krisha.
Для Krisha «Импортировать автоматически» ставит объявление в браузерную очередь:
расширение 0.4.8 открывает страницу, читает JSON и дополняет его явными полями
карточки. Если другая очередь работает или приостановлена, сначала завершите
или остановите её. «Загрузить без расширения» использует серверный импорт;
ограничение доступа сайта при этом остаётся возможным.

JSON выбирается по номеру или канонической ссылке текущего объявления. Данные
похожих квартир исключаются. Поддерживаются JSON-скрипты и JSON-объекты в известных
присваиваниях страницы; JavaScript страницы не выполняется. Явные характеристики
карточки имеют приоритет при расхождениях.

Полный стабильный JSON-снимок с автором, ремонтом, ипотекой, местоположением,
санузлами, описанием, фотографиями и обоими сравнениями цены может завершить
браузерный импорт после 2 секунд наблюдения и успешного сохранения. Если сведения
неполные, остаётся окно ожидания 12 секунд для дополнения из карточки. Между
объявлениями сохраняются прежние интервалы. Это условный быстрый путь, а не
обещание одинаковой скорости для всех страниц. Проверка на локальных примерах
не заменяет проверку JSON реального объявления.

Варианты добавления:
1. «Вставьте ссылку Krisha» — сервер пытается загрузить доступную страницу.
2. Расширение `browser-extension/` — передаёт публичные данные открытого объявления.
3. Bookmarklet из раздела «Импорт из браузера».
4. Ручная форма — если источник недоступен или не передаёт нужные поля.

В браузере с поддержкой локальных расширений включите режим разработчика на странице
расширений, выберите «Загрузить распакованное расширение» и каталог
`browser-extension`. В его настройках задайте `http://localhost:8000` или
`http://127.0.0.1:8000` и включите импорт. Также предусмотрены HTTPS-адреса
Codespaces. Другие адреса требуют соответствующих разрешений в manifest.

Версия расширения **0.4.14**. После обновления файлов нажмите «Обновить» у расширения
и обновите панель ApartmentAgent. Наличие расширения ChatGPT само по себе не означает,
что установлено расширение ApartmentAgent Browser Import.

Для пакетной очереди расширение использует разрешение на вкладки: оно позволяет
проверять адрес созданной им служебной вкладки и сохранять вкладки, в которых
пользователь начал другой переход. При обновлении подтвердите это разрешение,
если браузер его запросит. Версия 0.1.8 также ожидает окончания загрузки служебной
страницы вместо ошибочной остановки на промежуточном пустом адресе.

В версии 0.1.10 исправлено ложное распознавание проверки сайта: обычная подпись
reCAPTCHA внизу страницы не блокирует импорт квартиры с ценой, площадью и комнатами.
Явные страницы проверки браузера и ошибки доступа останавливают очередь.

В версии 0.2.1 строка «Работает в компании …» больше не принимается за адрес
квартиры. Ранее сохранённые значения обновляются при успешном повторном импорте.

В версии 0.2.2 обычные значки и служебные iframe reCAPTCHA не останавливают импорт,
даже если цена ещё загружается. Расширение продолжает ожидать данные объявления.
Явная страница проверки браузера, ошибка доступа или форма проверки по-прежнему
приостанавливают очередь; проверку сайта пользователь проходит вручную.

В версии 0.3.1 адрес из заголовка квартиры имеет приоритет перед общими адресными
блоками страницы. Поддерживается заголовок без этажа: «95.66 м², Айтматова 21».
Адрес офиса продавца и стандартная заглушка `empty-photo` не попадают в карточку.

Расширение повторно читает страницу при её перезагрузке, в том числе после
обновления расширения. Данные извлекаются из текущей разметки, а не из снимка
при запуске: если характеристики появились с задержкой, импорт дополняется.
Одинаковые данные в пределах одного открытия повторно не отправляются.
Уведомление об успешном сохранении отдельно сообщает, получено ли поле «Санузел».

Bookmarklet копируется из приложения и сохраняется как URL закладки. Запустите
закладку на открытой странице Krisha. Ограничения CSP, доступа к локальной сети
или смешанного содержимого могут помешать выполнению; тогда используйте расширение
или ручной ввод. Не отключайте защиту браузера ради импорта.

Повторный импорт обновляет карточку и записывает изменение цены. Варианты одной
ссылки с `www` и параметрами сопоставляются с существующей карточкой. Ранее созданные
дубликаты автоматически не объединяются. Сохранение через форму и импорт обновляют
связанный результат поиска: подтверждённые санузлы больше не остаются в списке
неподтверждённых. При возврате на вкладку приложения карточки обновляются.

У сохранённого результата поиска появляется «Открыть карточку». Ссылка ведёт
к этой квартире в разделе «Квартиры», выделяет её и раскрывает историю цены.
Если карточку скрывает фильтр рейтинга, при переходе выбирается «Все».
Адрес вида `/#listing-123` можно открыть повторно или сохранить в закладки.
При переходе по прямой ссылке панель открывает страницу с нужной карточкой.

### Просмотр сохранённых квартир

В разделе «Квартиры» показывается до **12 карточек на странице**. Кнопки
**«Назад»** и **«Дальше»** под списком переключают страницы. Фильтры и
сортировка применяются ко всем сохранённым карточкам в выбранном городе и
типе рынка. Номер объявления Krisha виден в карточке и в результатах поиска.

- В карточке показывается одно фото для предпросмотра, если оно есть.
  Раскройте **«Все фотографии»**, чтобы загрузить галерею.
- Раскройте **«Показать на карте»**, чтобы загрузить карту этой квартиры,
  если у неё есть координаты.
- Раскройте **«Сравнение цены за м²»**, чтобы запросить расчёт для этой карточки.

Ссылки на объявления открываются в новой вкладке. «Открыть и мониторить» дополнительно
запускает серверную попытку импорта; открытие вкладки само по себе не гарантирует
сохранение. На телефоне обработчик HTTPS-ссылок может открыть приложение Krisha.

## Данные карточки

- Цена, цена за м², комнаты, площадь, этажи, год и материал дома, фотографии.
- Число санузлов и признак «не менее». Значение поля Krisha «раздельный»
  означает один санузел с отдельными ванной и туалетом и не проходит фильтр
  «2 и более»; «совмещённый» также учитывается как один санузел.
  При браузерном импорте явная отдельная строка описания, например
  «2 санузла», может заполнить пропущенное значение. Характеристика
  объявления и ранее сохранённое количество имеют приоритет.
- Продавец и его роль по метке Krisha, ипотека: да / нет / не указано.
- В блоке «Проверка перед покупкой · eGov» есть список проверок документов и
  ссылка на официальную инструкцию. Инструкция открывается в новой вкладке.
- Условия ипотеки берутся из поля объявления, заголовка или описания. Подробнее
  в разделе [«Ипотека и оплата наличными»](#ипотека-и-оплата-наличными).
- Состояние ремонта и полное описание продавца.
- Если отдельное поле ремонта не получено, сервер ищет явное состояние квартиры
  в уже сохранённом описании. Такое значение помечается «По описанию автора»
  и сопровождается дословной цитатой. Формулировка «Квартира с ремонтом»
  сохраняется без придуманной оценки качества ремонта. Отдельное поле объявления и ручной ввод
  имеют приоритет. Ремонт крыши, подъезда, обещания будущего ремонта и противоречивые
  описания не становятся состоянием квартиры. Старые карточки обрабатываются
  автоматически при обновлении приложения, без открытия страниц или загрузки HTML.
- Все явно указанные характеристики объявления: материал и год дома, этажи,
  санузлы, кухня, потолки, балкон, мебель, парковка, залог и другие поля,
  когда они присутствуют на странице. Они раскрываются в блоке «Все характеристики».
- Город и район, включая обе записи «р-н Байконур» и «Байконур р-н».
- Адрес, координаты и ссылка на карту. Если координаты не получены, ссылка
  «Найти адрес на карте» передаёт карте сохранённый адрес дома; это отдельно
  поясняется в карточке.
  Случайно попавший в начало адреса префикс вроде «9 этаж,» удаляется;
  улицы с числом в названии, например «9 Мая», сохраняются.
- При наличии координат раздел **«Показать на карте»** раскрывает встроенный
  виджет Яндекс Карт с меткой квартиры. Большую карту можно открыть в новой
  вкладке. Для [виджета Яндекс Карт](https://yandex.ru/support/maps/ru/concept/get-map-reference)
  отдельный ключ JavaScript API не требуется.
- История цены, последняя разница, локальная оценка и кнопка проверки объявления.
- Описание ЖК с источником и временем получения.
- Сравнение цены за м² по двум независимым источникам.

«Дополнить карточки» с расширением **0.4.8** включает уже сохранённые квартиры,
если в них не получены ремонт, ипотека или тип продавца. Используются сохранённые
комнаты, бюджет, площадь, условие санузлов и фильтр залога. Объявления открываются
по очереди в браузере: нажимать каждую ссылку не требуется. После успешного
прохода той же версией обработки карточка автоматически не попадает в повторную
очередь, даже если в объявлении не удалось получить отдельные поля. Снятые
объявления пропускаются, при проверке безопасности очередь приостанавливается.
Панель отдельно показывает сохранённые карточки и пробелы по трём полям.
С расширением **0.4.2** нажатие «Продолжить» сохраняется на сервере. Если браузер
пропустил сигнал от вкладки, он увидит команду при следующей проверке состояния
очереди. При проверке безопасности по-прежнему требуется действие пользователя.
Панель показывает ожидание ответа на «Паузу» и «Продолжить». Если ответа нет,
она сообщает об этом и сверяет фактическое состояние очереди. Расширение
**0.4.3** восстанавливает опрос после кратковременного сбоя связи с приложением
и сохраняет время следующего объявления при ранней проверке состояния.

Явные поля объявления имеют приоритет над текстом описания. Имя автора берётся
из блока автора текущего объявления; явное заявление собственника в описании
может заполнить только тип автора с пометкой источника. Недоступные сведения
остаются неизвестными. Существующий полный текст и фотографии защищены от
замены краткими метаданными.
Расширение **0.4.4** читает явное поле «Состояние квартиры» и в блоках
характеристик, где подпись и значение оформлены без специальных классов.
Расширение **0.4.5** и закладка импорта показывают «сохранено» после
подтверждения от ApartmentAgent. В уведомлении указаны номер объявления
и номер карточки.
В версии **0.4.6** отсчёт времени импорта учитывает задержку первого запуска
проверки в браузере, чтобы данные можно было отправить после её начала.
В версии **0.4.7** отдельное поле «Состояние квартиры» также распознаётся
по строкам соседних характеристик в верхнем блоке объявления.

Неизвестные поля не заполняются предположениями. Рекламный ипотечный калькулятор
не является подтверждением возможности ипотеки. Признак в объявлении не заменяет
проверку условий банка.

### Ипотека и оплата наличными

Если продавец указывает «только за наличный расчёт», «только наличными» или
«исключительно наличными», ApartmentAgent показывает **«Ипотека: не предусмотрена»**
в карточке. Как и при «ипотеки нет» или «ипотека жоқ/жок», из расчёта рейтинга
вычитаются **25 баллов** и в поисковой выдаче, и в сохранённой карточке. Итоговый
балл ограничен шкалой 0–100. Объявление остаётся в результатах, если проходит фильтры.

Для условий из заголовка или описания в блоке «Ипотека» доступна цитата продавца.
Скидка за наличные, наличный первоначальный взнос и наличные как один из способов
оплаты сами по себе штрафа не дают. При запуске после обновления приложение также
проверяет уже сохранённые заголовки и описания.

### Залог

Фильтр «Исключать квартиры в залоге» включён по умолчанию. Он скрывает
подтверждённый залог из результатов поиска и пакетного дополнения.
Состояние берётся из поля или отметки «В залоге» в характеристиках квартиры
либо из прямой фразы о текущей квартире.
Оформление через банк или статус ипотеки сами по себе не определяют залог.
В сохранённых карточках залоговые варианты скрыты по умолчанию. Их можно
показать отдельной галочкой и отсортировать «Сначала без залога»:
подтверждённое отсутствие, неизвестно, затем подтверждённый залог.
Залог снижает рейтинг на 25 баллов.

## Рейтинг

Квартира на левом берегу Есиля получает **+5** в поисковой выдаче и в сохранённой
карточке. Максимум рейтинга — **100**. Берег определяется по координатам объявления
и линии русла из [OpenStreetMap](https://www.openstreetmap.org/relation/157622).
Точки вблизи русла, за пределами участка карты или без координат остаются без
подтверждённого берега. Галочка «Только левый берег» доступна в обоих списках.
Геоданные предоставлены [участниками OpenStreetMap](https://www.openstreetmap.org/copyright)
по лицензии ODbL.

Градация результатов поиска: от 85 баллов — «Срочно посмотреть», 65–84 —
«Проверить», ниже 65 — «Низкий приоритет». В сохранённой карточке применяется
более подробная оценка: от 90 — «ПОКУПАТЬ», 75–89 — «СМОТРЕТЬ», ниже 75 —
«НЕ РЕКОМЕНДУЮ». Балл отражает заданные критерии, а сравнение со средней ценой
показывается отдельно и на рейтинг не влияет.

## Сравнение цены за м²

**Средние Krisha.** Браузерные извлекатели читают явно подписанный блок
«Цена м² в похожих квартирах» для объявлений в Астане. Хранятся средние района и
города и подпись района.
«Получено со страницы» — время наблюдения приложением. Период статистики и число
объектов неизвестны, если источник их не передал. При импорте без блока прежние
значения и дата сохраняются. При новом неполном блоке поля относятся к одному
новому наблюдению, старые и новые средние не смешиваются.

**Собственная выборка.** Среднее арифметическое значений цена/площадь по другим
сохранённым квартирам того же города, обновлённым за последние 90 дней. Для каждой средней
нужно не менее пяти объектов. Оцениваемая квартира, дубликаты её URL, другие города,
устаревшие, проданные и снятые объявления исключаются. Районы нормализуются по поддерживаемым вариантам
названий. Это ограниченная выборка пользователя, зависящая от его фильтров.

Разница рассчитывается как `(цена за м² квартиры / среднее - 1) × 100%`.
Источники показываются отдельно; при недостатке данных средняя не подставляется.
Цены «от» в поиске обозначаются как нижняя граница, а не точная стоимость.

**Ближайшие аналоги.** Раскройте этот блок в сохранённой карточке. Сначала идут
объявления в том же ЖК, затем в других домах в радиусе до 1 км по координатам.
Используются сохранённые объявления того же города, обновлённые за последние 90 дней,
с тем же количеством комнат и площадью в пределах ±20%. В каждой группе есть
число подходящих квартир, цена за м² и ссылки на исходные страницы.

### Вероятные дубли у хозяина и риелторов

Раскройте **«Вероятные дубли»** в сохранённой карточке. Приложение сопоставляет
сохранённые объявления с одинаковым числом комнат и разницей площади до 0,5 м².
Для совпадения нужны одинаковый адрес с номером дома и этаж либо не менее двух
общих фотографий. Противоречия в известных данных о городе, адресе дома, этаже,
этажности или количестве санузлов исключают совпадение.
В блоке у каждого объявления своя строка. Рядом с его ценой указан его тип
продавца, например «Хозяин недвижимости» или «Риелтор · личность подтверждена».
В этой же строке доступны ссылка на публикацию и её статус.

См. [ручное подтверждение дублей](#7-ручное-подтверждение-дублей).

В **«Ближайших аналогах»** группа считается за одну квартиру. Для цены за м²
используется подходящее активное предложение хозяина, если оно есть. Иначе
используется самое свежее подходящее активное предложение. Раскройте
**«Все объявления»**, чтобы увидеть ссылки, цены и типы продавцов по всей группе.

### Проданные квартиры

Нажмите **«Отметить проданной»** в карточке. Её ссылка исчезнет из актуальной выдачи,
а из ближайших аналогов будет исключена вся группа вероятных дублей, даже если
другое объявление об этой квартире ещё активно. Ссылки и история цены доступны
через **«Показывать проданные и снятые»**. Отметку о продаже можно снять.

Krisha может пометить объявление архивным или снять его с публикации. Такой статус
хранится отдельно. Расширение 0.4.9 и новее распознаёт архив при открытии страницы.

## Описание ЖК и 2GIS

Описание ЖК доступно без ключа 2GIS: ручной текст с происхождением либо явно
подписанный блок «Описание ЖК» / «О жилом комплексе» из объявления. Для ссылочных
источников нужна ссылка, время получения назначает сервер. Описание квартиры
не подменяет описание комплекса. При повторном импорте без нового описания прежнее
сохраняется; при смене ЖК старый текст очищается, если нового нет.

Автоматический поиск сайтов застройщиков не реализован. Для источника «Сайт
застройщика» текст и ссылку можно внести вручную.

Рейтинг ЖК, количество отзывов и ссылка 2GIS — отдельная необязательная интеграция
с официальным Places API. Требуется `TWOGIS_API_KEY`. Без него карточка сохраняется
без обогащения 2GIS. Полный текст отзывов не загружается.
[Документация 2GIS](https://docs.2gis.com/en/api/search/places/overview).

## Контроль цены и настройки

По умолчанию фоновые поиск и автоимпорт включены. Сразу после запуска возможны
обращения к внешним источникам. Для просмотра интерфейса без фонового поиска
установите `SEARCH_ENABLED=false` в локальном `.env` и пересоздайте API-контейнер.

Основные параметры `.env`:
- `SEARCH_ENABLED`, `SEARCH_INTERVAL_MINUTES` (не меньше 15 минут).
- `AUTO_IMPORT_ENABLED` — импорт после поиска.
- `CHECK_INTERVAL_MINUTES` — проверка сохранённых квартир, по умолчанию 120 минут.
- `BRAVE_SEARCH_API_KEY` — необязательный резервный источник поиска.
- `TELEGRAM_ENABLED=true`, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` —
  уведомления об изменении и достижении целевой цены.
- `AI_ENABLED=true` — локальный анализ по правилам.
- `AI_REMOTE_ENABLED=true` и `OPENAI_API_KEY` — необязательный внешний анализ.
- `TWOGIS_ENABLED`, `TWOGIS_API_KEY`, `TWOGIS_REFRESH_HOURS`.

Ключи внешних сервисов не нужны для базового запуска. `.env` игнорируется Git.
Не добавляйте реальные ключи в исходники или `.env.example`.

## API

Полное описание запросов доступно в Swagger `/docs`.

- `POST /api/v1/search/run` — сохранить критерии и выполнить поиск.
- `GET /api/v1/search/status` — критерии, счётчики и состояние источников.
- `GET /api/v1/search/results` — подтверждённые результаты текущего отбора.
- `GET /api/v1/search/results?include_unconfirmed=true` — отдельная выборка
  с неизвестными санузлами при включённом отборе.
- `GET /api/v1/search/bathroom-check` — состояние очереди и число кандидатов.
- `POST /api/v1/search/bathroom-check/start` — создать очередь из неизвестных санузлов;
  тело `{"mode":"details"}` запускает дополнение характеристик сохранённых карточек.
- `POST /api/v1/search/bathroom-check/pause`, `/resume`, `/cancel` — управление очередью.
- `POST /api/v1/search/bathroom-check/claim`, `/complete` — задания расширения.
- `POST /api/v1/search/results/{id}/monitor` — попытка импорта и мониторинга.
- `POST /api/v1/listings` — ручное сохранение.
- `POST /api/v1/listings/import` — серверный импорт ссылки.
- `POST /api/v1/listings/olx-import` — сохранение или обновление карточки OLX
  по ссылке и переданным вручную характеристикам.
- `POST /api/v1/listings/browser-import` — сохранение полей браузерного извлекателя.
- `GET /api/v1/listings` и `GET /api/v1/listings/{id}` — карточки.
- `GET /api/v1/listings/{id}/comparison` — оба источника сравнения цены.
- `GET /api/v1/listings/{id}/price-history` — история наблюдений цены.
- `POST /api/v1/listings/{id}/check` — проверка одной квартиры.
- `POST /api/v1/checks/run` — проверка всех сохранённых квартир.
- `POST /api/v1/listings/{id}/ai-analysis` — пересчёт анализа.
- `GET /api/v1/notifications/status` — состояние Telegram.

Пример поиска в PowerShell 7:

```powershell
$criteria = @{
    rooms = 4
    max_price_kzt = 50000000
    min_area_m2 = 80
    max_area_m2 = 120
    min_bathrooms = 2
} | ConvertTo-Json
Invoke-RestMethod -Method Post http://localhost:8000/api/v1/search/run `
    -ContentType 'application/json' -Body $criteria
```

## Ограничения и проверенное поведение

При CAPTCHA браузерная очередь приостанавливается. HTTP 403, 429 и 468
включают защитную паузу той операции, которая получила ошибку. Поиск и
загрузка карточек Krisha возобновляются независимо. Цена и история
обновляются после успешного получения данных.

При проверке рабочей установки поиск Krisha вернул 48 объявлений, пока
загрузка карточек была на паузе после HTTP 468. Браузерный импорт также
проверен на реальных объявлениях. Если расширение не получило подтверждённого
количества санузлов, карточка сохраняется со значением «Не указано».

Для собственной выборки сравнения нужны сохранённые квартиры. Индекс отражает
цены предложения в выборке приложения.

Compose публикует порт 8000 на сетевых интерфейсах компьютера. Для установки
панели на телефон нужен адрес HTTPS. Список карточек, карта и заметки требуют
соединения с сервером.

Приложение поддерживает один пароль для панели и API. Задайте
`APP_AUTH_ENABLED=true`, `APP_AUTH_USERNAME` и `APP_AUTH_PASSWORD` в локальном
`.env` и пересоздайте контейнер. Для доступа извне нужна защищённая точка
входа HTTPS. Расширение текущей версии рассчитано на локальный режим без
HTTP-аутентификации. Codespaces требует проброса порта 8000.

## Разработка и проверки

Python 3.12+, Node.js для синтаксических проверок и DOM-примеров извлекателей.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install ".[dev]"
.\.venv\Scripts\python.exe -m pytest -q
node --check app/static/app.js
node tests/browser_extractor_test.js
node tests/browser_content_test.js
node tests/browser_queue_test.js
```

Проверки БД используют изолированный SQLite через `aiosqlite`; интеграционные
проверки миграций и API выполнялись отдельно на PostgreSQL. Подготовленные HTML/DOM
примеры не заменяют проверку реального сайта.
