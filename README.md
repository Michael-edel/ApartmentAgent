# ApartmentAgent

ApartmentAgent — сервис мониторинга и аналитики объявлений о продаже квартир в Астане с мобильной PWA-панелью для Android и iPhone.

## Цель MVP

Сервис принимает ссылки на объявления через веб-интерфейс или API, сохраняет карточки квартир, рассчитывает цену за квадратный метр, применяет пользовательские фильтры и формирует рейтинг объекта.

## Базовые критерии поиска

- город: Астана;
- полноценная 2-комнатная квартира;
- цена до 30 000 000 ₸;
- площадь 55–70 м²;
- не первый этаж;
- не последний этаж без технического этажа;
- предпочтительно кирпичный или монолитный дом;
- возможность покупки через Отбасы Банк.

## Архитектура MVP

- FastAPI — HTTP API и раздача PWA;
- адаптивная PWA-панель — работа в мобильном браузере и установка на главный экран;
- PostgreSQL — объявления, enrichment-поля, AI-анализ, snapshots цены и статусы импорта;
- Telegram Bot — уведомления о новых сильных объектах и изменении цены;
- Docker Compose — локальный запуск.

## Безопасность и ограничения

Проект не обходит CAPTCHA, 403/429, ограничения доступа и не маскирует автоматизацию. Если Krisha ограничивает запросы из Codespaces или другого IP, автоматический импорт останавливается, а результат получает статус блокировки. В этом случае ссылку можно открыть вручную и добавить данные через форму.

## Запуск на Windows

```powershell
git clone https://github.com/Michael-edel/ApartmentAgent
cd ApartmentAgent
if (!(Test-Path .env)) { Copy-Item .env.example .env }
docker compose up -d --build
```

После запуска:

- мобильная панель: `http://localhost:8000`;
- Swagger: `http://localhost:8000/docs`;
- health-check: `http://localhost:8000/health`.

Проверка контейнеров и журнал API:

```powershell
docker compose ps
docker compose logs --tail=150 api
```

### Запуск в GitHub Codespaces

```bash
cd /workspaces/ApartmentAgent
git pull --ff-only origin main
[ -f .env ] || cp .env.example .env
docker compose up -d --build --force-recreate
curl -i http://127.0.0.1:8000/health
```

В Codespaces нужно пробросить порт `8000` через вкладку **PORTS** и открыть сгенерированный адрес `https://...-8000.app.github.dev`. `localhost:8000` на телефоне указывает на сам телефон, а не на Codespace. Публичный доступ к порту следует включать только временно: приложение не содержит полноценной авторизации.

## Открытие с телефона в домашней сети

1. Узнайте IPv4-адрес компьютера командой `ipconfig`.
2. Убедитесь, что телефон подключен к той же Wi‑Fi сети.
3. Откройте в браузере `http://IP_КОМПЬЮТЕРА:8000`, например `http://192.168.1.15:8000`.
4. При необходимости установите PWA через меню браузера **Добавить на главный экран**.

Для доступа вне домашней сети нужен HTTPS-домен или безопасный туннель/VPN. Не открывайте порт 8000 напрямую в интернет без аутентификации и TLS.

## Реализовано

- адаптивная панель для мобильных браузеров;
- установка как PWA;
- офлайн-кэш оболочки;
- список квартир и фильтр по рейтингу;
- ручное добавление ссылки и ручной ввод при блокировке источника;
- браузерный импорт публичных данных со страницы Krisha через bookmarklet;
- автоматический браузерный импорт через расширение `browser-extension/`;
- автоматический импорт найденных подходящих ссылок после поиска, если источник разрешает загрузку;
- автоматическое обогащение доступными данными: фотографии, цена, цена за м², район, ЖК, год и материал дома;
- объяснимый локальный AI-анализ без обязательного внешнего API; опционально — OpenAI-compatible Chat Completions;
- расчет цены за м²;
- история изменения цены через API и в карточках PWA;
- рейтинг и вердикт объекта;
- дедупликация Telegram-событий;
- startup-миграция колонок для баз, созданных до v0.11;
- защита от дублирования ссылок.

## Фактические ограничения текущей версии

- Автоимпорт и enrichment зависят от доступности страницы объявления. При `403`, `429` или CAPTCHA карточка остаётся найденной ссылкой, но не становится сохранённой квартирой.
- Фото, район, ЖК, год постройки и материал дома появляются только после успешной загрузки страницы объявления или ручного заполнения.
- История цены и AI-анализ сохраняются для импортированных квартир; для одной только ссылки из поиска этих данных ещё нет.
- Telegram реализован, но не активирован без `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.
- Внешний AI реализован как опция. По умолчанию используется локальный анализ по правилам, а не облачная модель.
- Браузерный импорт получает только публичные поля, видимые на открытой странице. Cookies, токены и полный HTML страницы в API не отправляются.
- Codespaces подходит для проверки и личного использования, но остановленный Codespace не является постоянным хостингом. Для постоянной работы нужны сервер, HTTPS и авторизация.

### Как использовать браузерный импорт

1. Откройте ApartmentAgent через HTTPS-адрес Codespaces и перейдите к разделу **Импорт из браузера**.
2. Нажмите **Скопировать bookmarklet**.
3. Создайте в браузере закладку и вставьте скопированный текст в поле URL.
4. Откройте объявление Krisha обычным способом и запустите эту закладку.
5. ApartmentAgent примет цену, площадь, комнаты, этаж, фото и найденные дополнительные поля. После этого карточка будет сохранена или обновлена.

Если bookmarklet не смог определить обязательные поля, используйте ручной ввод. Он не обходит CAPTCHA и не извлекает закрытые данные.

### Полностью автоматический режим через расширение

В браузере, который поддерживает локальные расширения, можно установить каталог `browser-extension/` как unpacked extension:

1. Откройте страницу управления расширениями и включите режим разработчика.
2. Выберите **Load unpacked / Загрузить распакованное расширение** и укажите каталог `browser-extension`.
3. Откройте настройки расширения и укажите HTTPS-адрес ApartmentAgent, например `https://...-8000.app.github.dev`.
4. Включите автоматический импорт.

После этого расширение само запускается при открытии страницы объявления Krisha. На мобильных браузерах, где установка расширений недоступна, используйте bookmarklet из предыдущего раздела.

## API

- `POST /api/v1/search/run` — поиск и автоматический импорт найденных карточек;
- `GET /api/v1/search/results` — найденные ссылки и статус автоимпорта;
- `POST /api/v1/search/results/{id}/monitor` — запустить мониторинг перед открытием ссылки;
- `POST /api/v1/listings/import` — импорт и enrichment одной ссылки;
- `POST /api/v1/listings/browser-import` — сохранить данные, извлечённые bookmarklet-скриптом на открытой странице Krisha;
- `GET /api/v1/listings` — карточки с AI-анализом и историей цены;
- `POST /api/v1/listings/{id}/check` — проверить одну сохранённую квартиру и записать результат/изменение цены;
- `GET /api/v1/listings/{id}/price-history` — snapshots цены;
- `POST /api/v1/listings/{id}/ai-analysis` — пересчитать AI-анализ;
- `GET /api/v1/notifications/status` — состояние Telegram.

## Конфигурация новых функций

- `AUTO_IMPORT_ENABLED=true` включает импорт после каждого поиска. При ответе Krisha `403/429` или CAPTCHA новые запросы к источнику прекращаются, а оставшиеся результаты помечаются как `blocked` или `error`.
- `AI_ENABLED=true` включает explainable local-rules AI. `AI_REMOTE_ENABLED=true` и `OPENAI_API_KEY` включают дополнительный внешний анализ; при ошибке автоматически используется локальный fallback.
- `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` включают уведомления. Новые объекты фильтруются по `TELEGRAM_NOTIFY_MIN_SCORE`, а изменения цены дедуплицируются по event key.

Файл `.env` содержит локальные настройки и секреты. Его нельзя коммитить в Git; для старта используется `.env.example`.

В каждой сохранённой карточке есть кнопка **«Проверить квартиру»**. Она проверяет только выбранное объявление. Общая кнопка **«Проверить сейчас»** по-прежнему проверяет все сохранённые ссылки. Серверная проверка может получить блокировку Krisha; в этом случае откройте объявление через браузерное расширение, чтобы передать публичные данные с открытой страницы.

Порядок карточек можно изменить выбором сортировки **«Рейтинг»**, **«Цена за м²»** или **«Цена»**. В режиме **«Новые»** новые импортированные квартиры появляются сверху — это ожидаемое поведение.

Открытые карточки поиска не удаляются: после перехода по ссылке они получают пометку **«Просмотрено»**, но остаются в списке и сохраняют порядок по времени обнаружения.

Кнопка **«Открыть и мониторить»** сначала запускает добавление объявления в мониторинг, а затем открывает страницу Krisha. На Android ссылка запрашивает открытие именно в приложении Yandex Browser; если приложение недоступно или Android отклонит запрос, используется обычный HTTPS-переход. Если серверный импорт заблокирован, импорт завершается установленным браузерным расширением или bookmarklet на открытой странице.
