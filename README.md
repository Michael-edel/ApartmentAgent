# ApartmentAgent

ApartmentAgent — сервис мониторинга и аналитики объявлений о продаже квартир в Астане.

## Цель MVP

Сервис принимает ссылки на объявления через API или Telegram, сохраняет карточки квартир и историю цен, рассчитывает цену за квадратный метр, применяет пользовательские фильтры и формирует рейтинг объекта.

## Базовые критерии поиска

- город: Астана;
- 2-комнатная квартира;
- цена до 30 000 000 ₸;
- площадь 55–70 м²;
- не первый этаж;
- не последний этаж без технического этажа;
- предпочтительно кирпичный или монолитный дом;
- возможность покупки через Отбасы Банк.

## Архитектура MVP

- FastAPI — HTTP API;
- PostgreSQL — объявления, снимки и история цен;
- SQLAlchemy 2 + Alembic — доступ к данным и миграции;
- Telegram Bot — прием ссылок и уведомления;
- планировщик — периодические разрешенные проверки;
- Docker Compose — локальный запуск.

## Безопасность и ограничения

Проект не должен обходить CAPTCHA, 403/429, ограничения доступа или маскировать автоматизацию. При блокировке источник переводится в состояние `blocked`, а проверка прекращается. Основной сценарий MVP — анализ ссылок, полученных пользователем или официальными уведомлениями.

## Быстрый запуск

```bash
cp .env.example .env
docker compose up --build
```

API после запуска:

- `GET /health`
- `POST /api/v1/listings`
- `GET /api/v1/listings`

Документация: `http://localhost:8000/docs`
