Дополнительные условия и предпочтения

Обязательные условия исключают неподходящие варианты и объявления без подтверждённых данных. Предпочтения влияют на оценку.

Профили поиска

Сохраните критерии под именем и включите фоновый поиск. Активируйте профиль, чтобы применить его к основному поиску.

Фоновый поиск доступен только для Астаны. Профиль Экибастуза можно применить вручную.

Берег определяется по координатам объявления. © OpenStreetMap

Выберите город и другие критерии, затем нажмите «Искать сейчас». Они сохраняются для автоматических поисков. При отборе «От 2 санузлов» показываются только объявления с подтверждённым количеством.

Автопроверка объявлений

Для дополнения карточек нужно расширение ApartmentAgent 0.4.8 и открытый браузер. Нажмите «Дополнить карточки», чтобы получить недостающие сведения о ремонте, ипотеке или типе продавца. При проверке безопасности работа приостанавливается.
